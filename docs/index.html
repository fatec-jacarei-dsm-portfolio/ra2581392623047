Projeto API 3º Semestre

Contextualização: A GSW Software enfrenta desafios no gerenciamento de horas trabalhadas em projetos. O sistema atual de apontamento apresenta limitações técnicas, como lentidão e falhas de integração.

Objetivo: Desenvolver uma aplicação web robusta capaz de centralizar o controle de horas, fornecendo análises de produtividade para embasar decisões estratégicas baseadas em dados (Data-Driven).

Spring BootReactTypeScriptDockerMySQL

Metodologia: Criação de uma arquitetura orientada a microsserviços (APIs RESTful e interface SPA), substituindo controles descentralizados por um modelo integrado.

Resultados: Maior transparência sobre a produtividade interna, com geração de relatórios que permitem identificar gargalos e monitorar desvios de cronograma.

Minha atuação: Responsável pela modelagem relacional estruturada do banco de dados e desenvolvimento de interfaces. Implementei as camadas de segurança e controle de acesso aos endpoints utilizando RBAC (Role-Based Access Control).

A Experiência e Soft Skills Aplicadas:

Durante o projeto, o Trabalho em Equipe foi fundamental. Tive participação ativa nas reuniões do time (Daily), garantindo o alinhamento constante sobre o progresso das tarefas, o planejamento das Sprints e a rápida comunicação de impedimentos técnicos. Em conjunto, exerci a Proatividade ao tomar a frente em tarefas desafiadoras que não tinha tanto conhecimento. mas buscando soluções para não atrasar as entregas do grupo.

A Adaptabilidade rápida curva de aprendizado para dominar a linguagem Java e a arquitetura do framework Spring Boot do zero, aplicando os novos conceitos em tempo real no desenvolvimento do projeto, e atuando tanto no frontend, quanto no backend. Por fim, a Resiliência foi essencial para lidar com conteúdos de alta complexidade e curtos prazos de entrega. Um exemplo prático foi o desafio de entender como o retorno (JSON) do Keycloak funcionava, lendo sua documentação e tentando entender suas saidas, a partir disso, aplicar as regras de controle de acesso (RBAC).

04. PESSOAL_PROJETOS_DESTAQUES_

Pipeline Analítico de Criptomoedas

Descrição: Pipeline de engenharia de dados de ponta a ponta projetado para ingestão, orquestração e processamento de dados do mercado de criptomoedas.

Problema Identificado: Necessidade de extração e transformação automatizada (ELT) de dados voláteis do mercado financeiro para possibilitar análises confiáveis e em tempo hábil.

Solução Desenvolvida: Construção de um ambiente totalmente conteinerizado utilizando Docker. A solução orquestra fluxos complexos com Apache Airflow e executa transformações analíticas integradas via dbt e DuckDB através da biblioteca Astronomer Cosmos.

Desafios Técnicos: Garantir o isolamento das dependências dentro dos containers, estabelecer a comunicação assíncrona entre o Airflow e o Core do dbt, e assegurar a idempotência em todas as execuções das DAGs.

Resultados Obtidos: Pipeline altamente resiliente, operando sob os princípios de 12-factor apps (com variáveis de ambiente e logs estruturados), pronto para ser escalado e feito o deploy em provedores Cloud.

PythonDockerApache AirflowdbtDuckDBCosmos

Unicorn Startups EDA (Análise Exploratória)

Descrição: Estudo analítico profundo (Exploratory Data Analysis) sobre a base global de startups unicórnio, focado em extrair insights de valor de mercado e distribuição geográfica.

Problema Identificado: Dados de mercado altamente fragmentados e não estruturados sobre startups avaliadas em mais de 1 bilhão de dólares, dificultando a visão macroeconômica de investimentos.

Solução Desenvolvida: Aplicação de bibliotecas de manipulação de dados em Python para higienização da base (tratamento de nulos, conversão de moedas e datas) e construção de visualizações de dados interativas.

Desafios Técnicos: Padronização de dados financeiros globais e criação de narrativas visuais claras que pudessem traduzir métricas complexas para áreas de negócio (Data Storytelling).

Resultados Obtidos: Mapeamento claro e estruturado do ecossistema de unicórnios globais, evidenciando setores de maior crescimento e facilitando o entendimento de tendências de mercado baseadas em dados.

PythonPandasMatplotlib / SeabornJupyter
